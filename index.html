part D

1. What does the action attribute do?
The action attribute tells the form where to send the information after it is submitted.

2. What does the method attribute do?
The method attribute tells the form how the information should be sent, usually using GET or POST

3. Why is GET commonly useful for a search form?
GET is useful because the search information is shown in the URL, making the search results easy to share or bookmark.

4. Why might POST be used for a registration form?
POST is used because registration information is sent in the request body instead of being displayed in the URL.

5.Does using POST automatically make information secure?
No. POST does not automatically make information secure.
